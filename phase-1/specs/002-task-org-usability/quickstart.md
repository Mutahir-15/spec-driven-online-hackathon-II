# Quickstart: Phase 2 Features

## Prerequisites
- Python 3.x installed

## Running the Application
1. Run `python main.py`
2. Use option 1 to add tasks with different priorities and tags.
3. Use option 6 to search for specific words.
4. Use option 7 to filter by "High" priority.
5. Use option 8 to sort by Priority and see the order change.
